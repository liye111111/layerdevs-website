# LayerDevs Website

Official LayerDevs website, built with Astro and deployed as a static Cloudflare Pages project.

## Development

```bash
npm install
npm run dev
```

## Verification

```bash
npm run check
npm run build
```

## Cloudflare Pages

- Framework preset: `Astro`
- Build command: `npm run build`
- Output directory: `dist`
- Production branch: `main`

The production domain is `https://layerdevs.com`.
